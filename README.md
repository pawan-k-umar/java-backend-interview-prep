# Java Backend Interview Prep — 1000 Questions

Mobile-first PWA containing 1000 interview questions across Java, Spring Boot, transactions, REST, security, microservices, Kafka, AWS, Kubernetes, SQL/PostgreSQL, MongoDB, system design, testing, patterns, scenarios and project/leadership questions.

Every question has:
- Interview answer written to be spoken aloud
- Follow-up question
- Follow-up answer
- Tricky point
- Topic/category

## 7-day organization
Day 1: Core Java, Collections, Java 8
Day 2: Multithreading, JVM, Design Patterns
Day 3: Spring Core, Spring Boot, Transactions
Day 4: REST, Security, Testing
Day 5: Microservices, Kafka
Day 6: AWS, Kubernetes, SQL/PostgreSQL, MongoDB
Day 7: System Design, Scenario Based, Leadership & Project

## Add questions whenever needed
The app has an "Add Q" button. Use it for:
- company-specific questions after an interview
- questions you could not answer
- new topics/technologies
- questions found in job descriptions
- interviewer follow-ups you encounter

Custom questions are saved in the browser's localStorage.

## Run
python3 -m http.server 8080
Open http://localhost:8080

Deploy the folder to GitHub Pages or another static host, then use your phone browser's Add to Home Screen option.
